# Vehicle to Vehicle Communication Using Machine Learning and Pygame

## Project Overview
Vehicle to Vehicle (V2V) Communication using Machine Learning and Pygame is a smart transportation system project that simulates communication between vehicles in real time. The project uses Machine Learning algorithms to predict vehicle movement, detect possible collisions, and improve traffic safety.

Pygame is used to create a graphical simulation where vehicles move on roads, exchange data, and display alerts visually. The system helps demonstrate intelligent traffic management and autonomous driving concepts.

# How the System Works

1. Vehicles move inside the Pygame simulation window.
2. Each vehicle continuously shares information such as:
   - Speed
   - Direction
   - Distance
   - Position
3. Machine Learning models analyze vehicle data.
4. The system predicts possible collisions or traffic conditions.
5. Warning alerts are displayed on the screen.
